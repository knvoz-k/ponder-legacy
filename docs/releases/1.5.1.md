# Ponder Legacy 1.5.1

- 修复与新版 FTB Quests 同装时 FML 报告 `A mod sorting cycle was detected`、无法进入游戏的问题。
- 移除 Ponder 对 FTB Quests 的反向 `after:ftbquests` 约束。FTB Quests 可继续选择在 Ponder 后加载；任务链接、共享媒体及动态图片通过现有按需桥接启用，FTB Quests 保持可选。
- 新增基于 Forge 原生 ModSorter 的回归测试，复现旧声明的双向环，并检查新版 FTBQ、AE2S 教程附属、旧版 FTBQ 及未安装 FTBQ 的排序。

## 安装

仅将 `ponder-legacy-1.5.0.jar` 替换为 `ponder-legacy-1.5.1.jar`，不要同时保留两个版本。**AE2S Ponder Legacy 0.2.0 无需更新**。Minecraft 1.12.2 / Java 25 / Cleanroom **0.4.0 正式版（无 -alpha）**。

验收使用实际生产包，组合为 FTB Quests 1202.10.0-modern.10、FTB Library 5.5.4-modern.1、Media API 1.0.2、AE2S / Supergiant 1.1.0 与教程附属 0.2.0；同时检查未安装这些可选联动的核心环境。报告与哈希见 [安装包验收](../../LEGACY-VERIFICATION.md)。
