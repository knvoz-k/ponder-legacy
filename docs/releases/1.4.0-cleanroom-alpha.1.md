# Ponder Legacy 1.4.0 — Cleanroom Alpha 1

面向 Minecraft 1.12.2 / Java 25。最低 Cleanroom **0.4.0-alpha**；**0.4.0 正式版**已单独验收。此版本保持 Alpha。

## 安装

安装 `ponder-legacy-1.4.0-cleanroom-alpha.1.jar`，并独立安装 **CraftTweaker 4.1.20.698**。替换本项目旧 jar；`-api` 和 `-sources` 仅供开发。Cleanroom 已提供 MixinBooter 兼容接口。

MMCE **2.3.2** 为可选依赖。Ponder 内置适配代码，无需安装独立 Ponder-MMCE 附属，也不包含 MMCE 本体。

## 功能与改动

- JSON 场景包、Java 插件和 ZenScript API。
- F7 游戏内动画编辑器，支持时间轴、局部位移/旋转、撤销/重做、保存重载；F8 捕获方块、状态及方块实体 NBT。
- 物品与主题目录支持分类、搜索、滚动；同一物品的多个场景可通过悬浮菜单切换。
- 优化工具栏图标和悬停提示框进度条。
- 默认不安装演示；旧默认示例仅在内容未改动时移至备份目录，保留作者修改过的文件。
- MMCE 支持静态/动态结构、preview NBT、命名组、稳定指纹和蓝图场景映射，可用于 Java / ZenScript / JSON 与编辑器。
- 修复精确 Cleanroom 0.4.0-alpha / 0.4.0 的物理专服 Kirino 模组发现调用。
