# Ponder Legacy 1.6.1

## Markdown 图片和视频插入面板

- Markdown 编辑器新增 **插入图片 / 插入视频** 按钮，支持来源、标题／图片说明、宽高和视频封面。
- 游戏内文件选择器可浏览目录或打开粘贴的完整路径；外部文件自动复制到 `scripts/ponder/media/` 并生成可移植的本地引用。同名文件不会被覆盖，支持中文文件名导入。
- 插入为单次可撤销操作；取消不改变草稿，保留 YAML 元数据。支持校验、保存、重载与 F5 预览。
- 小窗口工具栏换行，表单可滚动且 Tab 自动定位；修复媒体宽高设置在预览中不生效的问题，视频点击区域与控制条随宽度同步。
- Revo UI 可选适配：Ponder 页面使用自身背景，避免背景模糊后处理影响编辑器、媒体面板或透明投影工具。

普通图片和编辑功能无需外置 Mod；**Media API 1.0.2** 仍为可选视频解码依赖。未安装时可编辑、保存，预览保留封面和缺失说明。FTB Quests 仍为可选任务媒体来源。AE2S Ponder Legacy 0.2.0 无需更新。

Minecraft 1.12.2 / Java 25 / 最低 **Cleanroom 0.4.0 正式版（无 -alpha）**。安装 `ponder-legacy-1.6.1.jar` 替换旧版本。保留 1.6.0 的世界内投影操作及 1.5.1 的 FTB Quests 加载顺序修复。

验收范围和生产安装包指纹见 [安装包验收](../../LEGACY-VERIFICATION.md)。
