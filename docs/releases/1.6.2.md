# Ponder Legacy 1.6.2

- 索引“模组”分类按当前语言显示名称，补充简体／繁体中文名称，包括 Minecraft、AE2S / Supergiant、应用气动、MMCE、FTB Quests 等。
- 中文名、英文原名和 Mod ID 均可搜索；切换语言保留选中分类和搜索词。
- 资源包可用 `ponder.mod_name.<注册命名空间>` 扩展或覆盖名称；也可读取模组的 `mod.<命名空间>.name`，没有翻译时保留元数据原名。
- 保留 Markdown 图片／视频面板、世界内投影和 Revo UI 可选适配。外置 Mod 均保持可选。

日志中的 `appliedpneumatics:air_network` 重复注册需要安装 **应用气动 1.0.9-cleanroom.2** 修复包：同一教程的多个物品关联复用一个 storyboard。Ponder 保留真实重复 ID 的诊断。

Minecraft 1.12.2 / Java 25 / 最低 **Cleanroom 0.4.0 正式版（无 -alpha）**。安装 `ponder-legacy-1.6.2.jar` 替换旧 Ponder。
