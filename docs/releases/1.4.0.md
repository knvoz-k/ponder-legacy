# Ponder Legacy 1.4.0

## Revo UI 适配

- 新增 Revo UI / 焕新 UI 的可选提示框适配，按实际行布局定位思索进度条。
- 修复进度条覆盖“按住 W”文字、延伸到左侧物品模型的问题。
- 支持标题换行、稀有度、标题图标、预览开关、字号与行距变化；关闭现代提示框时自动使用原版布局。
- Revo UI 与其依赖独立安装，Ponder 不要求安装它们。

## 环境

最低 **Cleanroom 0.4.0 正式版（无 `-alpha`）**，Minecraft 1.12.2、Java 25、CraftTweaker 4.1.20.698。
验收组合：Revo UI 0.8.7、NFR 0.8.0 full、ModularUI 3.2.0-nfr.2、AE2S / Supergiant 1.1.0。

安装 `ponder-legacy-1.4.0.jar` 并替换旧 Ponder Legacy jar。`-api`、`-sources`、`-mcp` 和开发 harness 不是运行安装文件。本次为正式发行版。

277 项单元测试、116 项编辑器与场景检查通过；Revo UI 安装/未安装分别通过 68 / 63 项客户端检查，两种组合均通过专服启动与场景执行。MMCE 2.3.2 客户端 / 专服分别通过 34 / 29 项检查。

NFR 0.8.0 首次生成的默认 TOML 存在重复 `[compat]`；验收使用合法最小配置，依赖 jar 未修改，处理说明见 Revo UI 文档。

验收、包哈希及限制见 [LEGACY-VERIFICATION.md](../../LEGACY-VERIFICATION.md)；依赖安装与适配说明见 [REVO-UI.md](../REVO-UI.md)。
