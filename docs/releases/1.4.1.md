# Ponder Legacy 1.4.1

## CraftTweaker 改为可选前置

- Ponder 本体不再要求安装 CraftTweaker；JSON 场景、Java API、结构框选与游戏内动画编辑器可以独立使用。
- 仅使用 ZenScript / `.zs` 场景时需要 CraftTweaker 4.1.20+，验收版本为 4.1.20.698。
- 隔离 CrT 日志与源码位置读取；未安装时移除引用 `IData` 的专用方法，避免缺类和反射方法解析失败。
- MMCE 脚本注册增加 CrT 存在检查。**MMCE 2.3.2 自身仍要求 CrT**，安装 MMCE 时仍需满足它的前置。
- Gradle 将 CrT 改为编译期依赖，避免 Maven 传递安装；开发客户端可用 `-PwithCraftTweaker` 启用。

## 安装与验收

Minecraft 1.12.2、Java 25、最低 **Cleanroom 0.4.0 正式版（无 `-alpha`）**。
替换旧运行包并安装 `ponder-legacy-1.4.1.jar`。`-api` 和 `-sources` 是开发文件。

279 项单元测试通过；CrT 未安装 / 已安装的客户端分别通过 126 / 127 项检查，物理专服分别通过 10 / 11 项检查。无 CrT 的 Revo UI + AE2S 客户端通过 68 项检查；MMCE + CrT 客户端 / 专服通过 34 / 29 项检查。未安装 CrT 时，类加载审计确认未加载 CrT、ZenScript 或可选诊断桥。
