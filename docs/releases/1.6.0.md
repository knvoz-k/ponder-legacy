# Ponder Legacy 1.6.0

## 投影直接在世界中操作

- 点击教程投影后立即回到世界，准星移动预览；玩家可走动与转动视角。
- 左键固定、右键旋转、滚轮调高低；Shift + 右键镜像、Shift + 滚轮前后微调，Esc 取消。固定后恢复普通建造操作，蹲下 + 中键可重新抓取。
- 取消移动会恢复原投影的位置、旋转和镜像。无需填写 XYZ，也不新增全局快捷键。
- 选项改为透明工具面板，保留世界画面；「更多」收纳显示层、隐藏已建、显隐与材料面板布局。

## 可见性修复

- 连续透明模型替换旧网点，增加高亮边框及黄色原点；被墙或地形挡住时仍有轮廓。
- 底板识别检查实际存在的方块，修复仅声明底板时误删第一层机器的问题；非空结构不会因移除底板变成空模板。
- 新投影以底面中心对准准星，避免大型模板出现在视野外。材料 HUD 也避让原版通知。

保留 1.5.1 的 FTB Quests 加载顺序修复。AE2S 教程附属 **0.2.0 无需更新**。

## 安装与验收

Minecraft 1.12.2 / Java 25 / 最低 **Cleanroom 0.4.0 正式版（无 -alpha）**。安装 `ponder-legacy-1.6.0.jar`，替换旧 Ponder jar。

307 项单元测试。生产包实机检查草地上的预览、鼠标固定／旋转／镜像／高低与距离、抓取与撤销、透明面板、遮挡轮廓及原生 AE2S 模型；同时检查专服和可选联动，见 [安装包验收](../../LEGACY-VERIFICATION.md)。投影仅提供搭建指引，不自动放置方块。
