# Ponder Legacy 1.5.0

## 动画与静态图文

- W 为唯一教程入口。可切换动画／静态图文，并保存默认形式。
- 一份 Markdown 生成讲解、动画动作与静态 3D 快照，支持按展示特化和多场景物品。
- 静态页面具备搜索分类、独立滚动目录、交互 3D、配方、图片和表格。游戏内 F7 编辑 Markdown，提供选区、撤销重做、校验保存和预览。
- 移植 GuideME 独立 MIT Markdown 模块，保留版权和来源；无需安装现代 GuideME。

## 媒体与建造

- 普通图片内置加载；FTB Quests 可选提供任务跳转、共享媒体及动态图片，Media API 可选提供视频播放与跳转。
- 一键将结构投影到世界，支持原点、旋转、镜像、层、底板与已建方块过滤。
- 检查背包材料并钉住 HUD／背包。拖动标题栏移动；HUD 位置通过管理页或 `/ponderprojection layout` 调整，两种位置独立保存。
- 面板避开容器、配方书及常见 HUD 区域；窄窗口收起为摘要，提示框保持在上方。自定义模组覆盖层可手动避让。
- 按钮和媒体控制使用较大的像素图标，星号、书本、投影与材料均可辨识。

## 环境与安装

Minecraft 1.12.2 / Java 25 / 最低 **Cleanroom 0.4.0 正式版（无 -alpha）**。安装 `ponder-legacy-1.5.0.jar`，替换旧版本。CraftTweaker 仅在 ZenScript 或外部模组自身要求时安装；FTB Quests、Media API、MMCE、Revo UI 均为可选依赖。

300 项单元测试；生产安装包的客户端、专服、可选媒体与 Revo UI 验收见 [安装包验收](../../LEGACY-VERIFICATION.md)。Linux 使用 llvmpipe，未覆盖全部硬件和整合包。投影不代建，材料表不计算容器内物品与机器配置 NBT。
