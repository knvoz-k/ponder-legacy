# Ponder Legacy 中文说明

当前版本的中文介绍、安装要求、编辑器操作与 API 入口统一维护在 **[README.md](README.md)**。

- Minecraft 1.12.2；Java 25；最低 Cleanroom **0.4.0-alpha**，正式 **0.4.0** 另行验收。
- CraftTweaker **4.1.20.698** 为必需依赖；MMCE **2.3.2** 为可选依赖。
- 支持 JSON / Java / ZenScript、F7 动画编辑器、F8 结构框选、分类滚动目录及同物品多场景菜单。
- 默认不安装示例；MMCE 适配不会自动生成机器教程。
- 安装包和校验文件见 [GitHub Releases](https://github.com/mcyudream/ponder-legacy/releases)，验收范围见 [LEGACY-VERIFICATION.md](LEGACY-VERIFICATION.md)。

历史 Forge / Java 8 文档保留在 [Forge 基线文档](docs/FORGE-BASELINE-README.md)，当前 Cleanroom 版本以主 README 为准。
